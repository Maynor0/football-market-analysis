# Sports Analysis Systems

Repositorio con plantillas y documentación para análisis de córners, tarjetas, BTTS y validación de mercado.

## Overview

Este proyecto reúne varios módulos de análisis deportivo y sus plantillas de trabajo.

## Modules

- Cornv8.
- TarjetaV1.
- AmbosSi0No.
- Validación de Mercado.

## Usage

1. Lee la documentación de cada módulo.
2. Usa la plantilla correspondiente.
3. Revisa los ejemplos antes de editar tus propios datos.

## Notes

No es una versión final.  
La idea es contrastar el análisis con otras perspectivas, detectar puntos débiles y seguir mejorándolo.

## Data Sources

- WhoScored.
- FBRef.
- Pronosticosfutbol.
- Datos internos de las plantillas.
