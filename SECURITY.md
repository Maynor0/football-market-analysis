\# Security Policy

\## Reporting a vulnerability

If you believe you have found a security vulnerability in this repository, please do not open a public issue.

Please report it privately through GitHub's security reporting flow or contact the maintainers through the repository's security channel.

Include, when possible:

- A short description of the issue.
- The affected file or section.
- Steps to reproduce.
- Any relevant screenshots or examples.

We will review the report and respond as soon as possible.
