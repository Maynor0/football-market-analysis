\# Sports Analysis Systems

Repositorio con plantillas y documentación para análisis de apuestas deportivas.

\## Requirements

- Excel o Google Sheets.
- Datos históricos de partidos.
- Acceso a fuentes como WhoScored, FBRef o similares.

\## Workflow

1. Abrir la plantilla.
1. Cargar datos del partido.
1. Validar el mercado.
1. Revisar el resultado con el tutorial correspondiente.

\## Data Sources

- WhoScored.
- FBRef.
- Pronosticosfutbol.
- Datos internos de las plantillas.

\## Contributing

Si quieres mejorar el sistema, abre un issue o envía un pull request con:

- nueva métrica,
- mejora de fórmula,
- o ejemplo real.

\## Notes

La documentación completa está en `docs/`. Este README solo sirve como entrada rápida al repositorio.

Esta versión no es la final.

La idea es contrastar el análisis con otras perspectivas, detectar puntos débiles y seguir mejorándolo.
